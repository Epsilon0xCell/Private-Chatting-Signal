Private-Chatting-Signal: a signal lamp for one link

One lamp, one beam, one answer across the water. This repository holds exactly one thing: the way to reach a private conversation on Signal.

Harbour notice

Private conversation stays private. This page names no person, no number, and no handle; it only points at the Signal service itself, where the conversation, once opened, belongs to the people in it.

Everything else about the exchange happens on Signal, off this quay, with the shutters closed behind it.
